Meridian Statistics — a national statistics explorer for eight countries: population, GDP, life expectancy, emissions and more, every figure with its source and year, ten-year charts, regional breakdowns, a two-country compare tool and an indicator ranking explorer. Static files only, no build step, works offline on desktop and phone.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To browse the site itself, serve `app/` with any static file server and open `index.html`.
